Run the exercises

PHP needs a server to execute.

GitHub Pages hosts static HTML, CSS, and JavaScript, but it does not execute PHP. This dashboard works on GitHub Pages; the actual lesson files need a PHP server such as Apache through XAMPP.

!

Important: Opening a .php file directly or through GitHub Pages will not run its PHP code.

Run locally with XAMPP

  1. 1
    Install XAMPP

    Download and install XAMPP on your computer.

  2. 2
    Add the repository

    Clone or place it inside the xampp/htdocs folder.

  3. 3
    Start Apache

    Open the XAMPP Control Panel and start Apache.

  4. 4
    Open localhost

    Visit the project through your browser.
